# Lite Calculator · 用 GPUI 写的原生计算器

中文 | [English](README.md)

基于 [GPUI Kit](https://gpui-kit.com) 的原生桌面计算器：标准模式与科学模式一键切换，DEG/RAD 切换，进制 / 角度 / 单位换算面板，深浅色主题，输入时实时预览结果，支持物理键盘。全部 Rust，没有 Electron、没有 WebView，产物是单个原生可执行文件。

## 特性

- **双模式键盘**：标准 19 键；科学模式在上方追加 24 个函数键，数字区自动收窄，同一个窗口内完成切换。
- **表达式即所见**：显示区是可读表达式而不是内部状态码，后缀键直接写成 `^2`、`^-1`、`!`、`mod`，按 `=` 时自动补齐未闭合的括号。
- **实时预览**：输入过程中在第三行显示 `= 结果`，非法或不完整表达式不会打断输入。
- **DEG / RAD**：影响 `sin cos tan` 与反三角函数的返回值。
- **换算面板**：覆盖式弹层，包含进制转换（BIN / OCT / DEC / HEX）、角度转换（DEG ↔ DMS ↔ 弧度 ↔ 百分度）和 7 类单位换算（长度、面积、体积、重量、速度、时间、温度）。面板自带键盘并独占按键路由，与计算器显示区互不干扰。
- **深浅色主题**：标题栏按钮一键切换，配色全部取自 GPUI 主题（跟随 `background / muted / foreground / border / danger`）。
- **物理键盘输入**：数字、运算符、括号、`Enter`、`Backspace`、`Esc` 直接可用，科学模式下字母键触发函数。
- **历史记录与 `Ans`**：保留最近一次表达式与结果，`Ans` 键把它插入当前表达式，可一键清空。
- **有意义的错误**：`表达式无效`、`除数为零`、`输入超出定义域`、`数值超出范围`，而不是空白或 `NaN`。
- **可回归的测试**：`cargo test` 跑 23 个用例——16 个引擎与换算单元测试 + 7 个 GPUI 无头 UI 集成测试（真实命中测试的点击与按键事件）。

## 快速开始

```bash
cargo run              # 调试构建运行（dev profile 已开 opt-level = 1，GPUI 在纯 debug 下偏慢）
cargo build --release  # 发布构建
./scripts/build-app.sh # 打包 dist/LiteCalculator.app 与 dist/*.zip
```

环境要求：

- Rust 1.85 及以上（`Cargo.toml` 里的 `rust-version`）。
- 已在 macOS 26.4 / Apple Silicon 上构建并运行验证。GPUI 同样支持 Linux 与 Windows；Windows 可执行文件与安装包由 GitHub Actions（`.github/workflows/release.yml`）产出并挂到每个 release，macOS 上无法交叉编译所以不走本地打包。

## 界面

窗口从上到下：

1. **标题栏**：应用名与当前模式标签，右侧是主题切换按钮。
2. **显示区**：第一行是角度单位与上一条记录，中间是表达式或结果（字号按长度自适应，超长时从头部省略），第三行是错误提示、`= 预览结果`，或输入提示。
3. **模式条**：`标准 / 科学` 分段切换，右侧依次是 `换算`、`DEG/RAD` 与 `清除历史`。
4. **键盘**：科学模式下先出现函数面板，再接数字区。
5. **换算弹层**（打开时）：半透明遮罩上叠一张卡片，包含类型选择、源/目标选择、输入行、结果行和自带键盘。

标准键盘：

| | | | |
| --- | --- | --- | --- |
| `AC` | `⌫` | `%` | `÷` |
| `7` | `8` | `9` | `×` |
| `4` | `5` | `6` | `−` |
| `1` | `2` | `3` | `+` |
| `±` | `0` | `.` | `=` |

科学面板（4 × 6）：

| `x²` | `x³` | `xʸ` | `1/x` | `n!` | `mod` |
| `(` | `)` | `|x|` | `π` | `e` | `Ans` |

## 物理键盘

| 按键 | 作用 |
| --- | --- |
| `0`–`9`、`.` | 数字与小数点 |
| `+` `-` `*` `/` | 四则运算 |
| `^` `%` `!` | 幂、百分号、阶乘 |
| `(` `)` | 括号 |
| `Enter` 或 `=` | 求值 |
| `Backspace` | 删除一个完整 token（`sin(`、`^2`、` mod ` 等整体删除） |
| `Esc` 或 `Delete` | 全部清除 |
| `π` | 圆周率（macOS 上 `⌥G`） |

仅在科学模式生效：`s` `sin` · `c` `cos` · `t` `tan` · `l` `ln` · `g` `log` · `r` `√` · `q` `x²` · `p` `π`。

带 `⌘` / `⌥` / `Ctrl` 的组合键一律忽略，不与系统快捷键冲突。

换算面板打开时按键会改路由给面板：数字、`.`、`:`、`-` 写入输入缓冲，`A`–`F` 在十六进制下可用，`Backspace` 删除一个字符，`Delete` 清空缓冲，`Esc` 关闭面板。

## 表达式语法

优先级从低到高：

```
+ −            加减
× ÷ mod        乘除与取模（含隐式乘法）
一元 −         正负号
^              幂，右结合
! %            后缀阶乘与百分号
原子            数字 / 常数 / 函数 / 括号
```

- **隐式乘法**：`2π`、`3(1+2)`、`2sin(30)` 都会按乘法处理。
- **后缀键写入文本**：`x²` → `^2`，`x³` → `^3`，`1/x` → `^-1`，`n!` → `!`，`%` 是除以 100。
- **函数**：`sin cos tan asin acos atan ln log log2 sqrt ∛(cbrt) abs exp`；引擎另外实现了 `sinh cosh tanh round floor ceil`，当前键盘没有分配按键。
- **常数**：`π`、`e`。
- **自动补括号**：求值前按左右括号差值补齐右括号，`sin(30` 直接按 `=` 也能算。
- **数值格式**：约 12 位有效数字，落在 `1e-6` 到 `1e12` 之外改用科学计数法；阶乘支持 `0!` 到 `170!`。

## 换算

模式条上的 `换算` 按钮会弹出覆盖式卡片；底层计算器状态保持不变，`Esc`、卡片上的 `✕` 或再次点击按钮都会收起它。三种换算共用同一张卡片：

- **进制**：先选 BIN / OCT / DEC / HEX 作为输入进制，卡片同时给出十进制、十六进制、八进制、二进制和位宽。输入是不超过 `2⁶⁴ − 1` 的无符号整数；选定制进制不支持的数字会被忽略，溢出显示 `数值超出范围` 而不是回绕。
- **角度**：支持十进制度（`40.446`）和度分秒（`40:26:46.2`）两种输入，输出十进制度、`° ′ ″`、弧度和百分度。秒保留 4 位小数并会向前进位，`59.9999″` 会进到分与度。
- **单位**：先选类别，再选源单位与目标单位。卡片给出换算结果，温度以外还会显示 `1 源 = 系数 目标` 的倍率。

| 类别 | 单位 |
| --- | --- |
| 长度 | mm · cm · m · km · in · ft · yd · mi |
| 面积 | cm² · m² · km² · 公顷 · 英亩 · in² · ft² |
| 体积 | ml · L · m³ · gal · fl oz · ft³ |
| 重量 | g · kg · t · lb · oz |
| 速度 | m/s · km/h · mph · kn · ft/s |
| 时间 | ms · s · min · h · day · week |
| 温度 | °C · °F · K |

温度用偏移量换算而不是固定倍率，所以这一类刻意不显示倍率行。切换换算类型、进制或单位类别会清空输入缓冲，只更换源/目标单位不会。

## 项目结构

```
Cargo.toml                 依赖只有 gpui-kit = "0.7.1"（dev-dependencies 额外开 test-support）
src/main.rs             ~30 行   应用入口、标题栏窗口选项、初始与最小窗口尺寸
src/engine.rs          ~900 行   按键语义、计算器状态机、递归下降解析器、求值与格式化
src/convert.rs         ~800 行   换算引擎：进制/角度/单位表、输入缓冲、结果行与单元测试
src/view.rs           ~1100 行   GPUI 界面：显示区 / 模式条 / 键盘 / 换算弹层 / 按键映射 / 无头 UI 测试
scripts/build-app.sh                  macOS .app 打包与 zip
.github/workflows/release.yml         macOS 与 Windows 发布构建、Windows 安装包，按 v* 标签触发
```

## 已知限制

- 未做代码签名与公证。macOS 首次打开请右键 → **打开**，或执行 `xattr -dr com.apple.quarantine LiteCalculator.app`。
- 计算结果只有 `f64` 十进制精度，没有任意精度、复数与分数；换算是精确的（进制限于无符号 64 位整数，单位走固定倍率）。
- 没有内存键（`M+` / `MR`），表达式和换算输入都不能移动光标编辑，只能整体退格或清空。
- 换算输入缓冲最多 24 个字符，不支持指数输入与千分位分隔。
- 界面文案为中文，未接入 i18n。
- Linux 未实测。Windows 由 CI（`.github/workflows/release.yml`）构建，但本机没有 Windows 环境可实机操作，Windows 产物按社区验证看待。
