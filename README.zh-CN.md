# Lite Calculator · 用 GPUI 写的原生计算器

中文 | [English](README.md)

基于 [GPUI Kit](https://gpui-kit.com) 的原生桌面计算器：标准模式与科学模式一键切换，DEG/RAD 切换，深浅色主题，输入时实时预览结果，支持物理键盘。全部 Rust，没有 Electron、没有 WebView，产物是单个原生可执行文件。

## 特性

- **双模式键盘**：标准 19 键；科学模式在上方追加 24 个函数键，数字区自动收窄，同一个窗口内完成切换。
- **表达式即所见**：显示区是可读表达式而不是内部状态码，后缀键直接写成 `^2`、`^-1`、`!`、`mod`，按 `=` 时自动补齐未闭合的括号。
- **实时预览**：输入过程中在第三行显示 `= 结果`，非法或不完整表达式不会打断输入。
- **DEG / RAD**：影响 `sin cos tan` 与反三角函数的返回值。
- **深浅色主题**：标题栏按钮一键切换，配色全部取自 GPUI 主题（跟随 `background / muted / foreground / border / danger`）。
- **物理键盘输入**：数字、运算符、括号、`Enter`、`Backspace`、`Esc` 直接可用，科学模式下字母键触发函数。
- **历史记录与 `Ans`**：保留最近一次表达式与结果，`Ans` 键把它插入当前表达式，可一键清空。
- **有意义的错误**：`表达式无效`、`除数为零`、`输入超出定义域`、`数值超出范围`，而不是空白或 `NaN`。
- **可回归的测试**：`cargo test` 跑 11 个用例——7 个引擎单元测试 + 4 个 GPUI 无头 UI 集成测试（真实命中测试的点击与按键事件）。

## 快速开始

```bash
cargo run              # 调试构建运行（dev profile 已开 opt-level = 1，GPUI 在纯 debug 下偏慢）
cargo build --release  # 发布构建
./scripts/build-app.sh # 打包 dist/LiteCalculator.app 与 dist/*.zip
```

环境要求：

- Rust 1.85 及以上（`Cargo.toml` 里的 `rust-version`）。
- 已在 macOS 26.4 / Apple Silicon 上构建并运行验证。GPUI 本身支持 Linux 与 Windows，但本项目尚未在这两个平台上实测。

## 界面

窗口从上到下：

1. **标题栏**：应用名与当前模式标签，右侧是主题切换按钮。
2. **显示区**：第一行是角度单位与上一条记录，中间是表达式或结果（字号按长度自适应，超长时从头部省略），第三行是错误提示、`= 预览结果`，或输入提示。
3. **模式条**：`标准 / 科学` 分段切换，右侧是 `DEG/RAD` 与 `清除历史`。
4. **键盘**：科学模式下先出现函数面板，再接数字区。

标准键盘：

| | | | |
| --- | --- | --- | --- |
| `AC` | `⌫` | `%` | `÷` |
| `7` | `8` | `9` | `×` |
| `4` | `5` | `6` | `−` |
| `1` | `2` | `3` | `+` |
| `±` | `0` | `.` | `=` |

科学面板（4 × 6）：

| | | | | | |
| --- | --- | --- | --- | --- | --- |
| `sin` | `cos` | `tan` | `sin⁻¹` | `cos⁻¹` | `tan⁻¹` |
| `ln` | `log` | `log₂` | `eˣ` | `√` | `∛` |
| `x²` | `x³` | `xʸ` | `1/x` | `n!` | `mod` |
| `(` | `)` | `|x|` | `π` | `e` | `Ans` |

## 物理键盘

| 按键 | 作用 |
| --- | --- |
| `0`–`9`、`.` | 数字与小数点 |
| `+` `-` `*` `/` | 四则运算 |
| `^` `%` `!` | 幂、百分号、阶乘 |
| `(` `)` | 括号 |
| `Enter` 或 `=` | 求值 |
| `Backspace` | 删除一个完整 token（`sin(`、`^2`、` mod ` 等整体删除） |
| `Esc` 或 `Delete` | 全部清除 |
| `π` | 圆周率（macOS 上 `⌥G`） |

仅在科学模式生效：`s` `sin` · `c` `cos` · `t` `tan` · `l` `ln` · `g` `log` · `r` `√` · `q` `x²` · `p` `π`。

带 `⌘` / `⌥` / `Ctrl` 的组合键一律忽略，不与系统快捷键冲突。

## 表达式语法

优先级从低到高：

```
+ −            加减
× ÷ mod        乘除与取模（含隐式乘法）
一元 −         正负号
^              幂，右结合
! %            后缀阶乘与百分号
原子            数字 / 常数 / 函数 / 括号
```

- **隐式乘法**：`2π`、`3(1+2)`、`2sin(30)` 都会按乘法处理。
- **后缀键写入文本**：`x²` → `^2`，`x³` → `^3`，`1/x` → `^-1`，`n!` → `!`，`%` 是除以 100。
- **函数**：`sin cos tan asin acos atan ln log log2 sqrt ∛(cbrt) abs exp`；引擎另外实现了 `sinh cosh tanh round floor ceil`，当前键盘没有分配按键。
- **常数**：`π`、`e`。
- **自动补括号**：求值前按左右括号差值补齐右括号，`sin(30` 直接按 `=` 也能算。
- **数值格式**：约 12 位有效数字，落在 `1e-6` 到 `1e12` 之外改用科学计数法；阶乘支持 `0!` 到 `170!`。

## 项目结构

```
Cargo.toml              依赖只有 gpui-kit = "0.7.1"（dev-dependencies 额外开 test-support）
src/main.rs          ~30 行   应用入口、标题栏窗口选项、初始与最小窗口尺寸
src/engine.rs       ~900 行   按键语义、计算器状态机、递归下降解析器、求值与格式化
src/view.rs         ~570 行   GPUI 界面：显示区 / 模式条 / 键盘 / 按键映射 / 无头 UI 测试
scripts/build-app.sh          macOS .app 打包与 zip
```

## 已知限制

- 未做代码签名与公证。macOS 首次打开请右键 → **打开**，或执行 `xattr -dr com.apple.quarantine LiteCalculator.app`。
- 仅 `f64` 十进制结果，没有任意精度、复数、分数或单位换算。
- 没有内存键（`M+` / `MR`），表达式不能移动光标编辑，只能整体退格或清空。
- 界面文案为中文，未接入 i18n。
- Linux / Windows 未实测。
